Multi-Framework Rust Integration

Copy ready-to-use code for your favorite framework (GPUI, egui, Iced, Leptos, Dioxus)

cargo add morpheusicons --features leptos

Quick Install

Add MorpheusIcons to your Rust project in seconds. Works with any GUI framework.

cargo add morpheusicons

Then add a feature flag for your framework: --features leptos, --features egui, --features gpui, --features iced, or --features dioxus
