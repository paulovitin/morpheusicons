# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone, regardless of background or identity.

## Standard

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please read it in full — it defines expected behavior, unacceptable behavior, and enforcement responsibilities.

## Scope

This Code of Conduct applies within all project spaces (issues, PRs, discussions, chat) and in public spaces when representing the project.
